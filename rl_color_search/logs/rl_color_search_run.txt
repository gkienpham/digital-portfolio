Goal: GREEN    Boundary (both ends): BLACK
The robot discovers the other brick colors as it explores.
The Q-table starts empty: each new color adds a row.
Rewards: goal +10, boundary -10, any other move -1
Learning: alpha 0.50, gamma 0.90, epsilon 0.10 (chance of a random move while training)

  RIGHT button = TRAIN one episode (explore + learn)
  LEFT button  = TEST what it learned (no random moves, no learning)
  Press either button during a run to stop it.
