Project 14: Smart Walkers (RL)

The Smart Walker challenge was to use reinforcement learning to teach a “Silly Walk” robot to walk straight. The robot is a LEGO SPIKE Prime build with lopsided legs, so on its own it doesn’t walk in a straight line. It also has to be built so it doesn’t flip over.

The steps were to build the Silly Walks robot, run the provided rl_smart_walker.py code from the RLwithSPIKE repository by Ethan Danahy and the Tufts CEEO, watch the Q-table on the live web dashboard, and try different types of legs.
